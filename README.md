# Naro Hackathon

AI 기반 선택지 비교 및 실행 계획 관리 서비스

## MVP

1. 선택지 입력 / AI 구조화
2. 선택지 지도 시각화
3. 사용자가 경로 생성
4. AI 경로 비교 분석
5. 메인 경로 선택
6. AI 할 일 생성

## Run Frontend

```bash
cd frontend
npm install
npm run dev
```

## Run Backend

```bash
cd backend
npm install
npm run dev
```

## API

GET /api/health (확인용)
POST /api/compare-routes
